# Trade sounds

Put your own sound here as `profit.wav` (or `profit.mp3`) and the app uses it instead of its built-in bell:

- a trade that closes in profit plays the file as it is;
- a stop loss or any losing close plays the same file at half speed, which is exactly one octave lower.

Without a file the app plays its own synthesised bell (a short, bright "ding"). Test both in
Settings > Manual trading > "Play profit bell" / "Play loss bell". Restart the app after adding a file.
